PORTFOLIO — ANNE OKITO
Site vitrine statique, prêt à être déployé sur Vercel.

FICHIERS
- index.html : contenu et sections du portfolio
- styles.css : mise en page, couleurs et adaptation mobile
- script.js : menu mobile et année automatique

MODIFICATIONS À FAIRE AVANT PUBLICATION
1. Remplacer les images Unsplash par vos propres photos de projets, rendus Revit/Lumion et photos de chantier.
2. Vérifier les intitulés et descriptions des projets et ne publier que les images dont vous détenez les droits.
3. Remplacer les liens génériques Facebook et LinkedIn par vos profils exacts.
4. Ajouter éventuellement un numéro WhatsApp professionnel et un CV PDF.
5. Vérifier l'adresse e-mail de contact.

DÉPLOIEMENT SUR VERCEL — MÉTHODE SIMPLE
1. Décompresser le dossier.
2. Créer un dépôt GitHub et y téléverser les trois fichiers (index.html, styles.css, script.js) et ce README si souhaité.
3. Sur vercel.com, choisir Add New → Project, importer le dépôt GitHub.
4. Framework Preset : Other. Build Command : laisser vide. Output Directory : laisser vide ou utiliser le dossier racine selon l'interface. Install Command : laisser vide.
5. Cliquer Deploy. Vercel publiera le site.

Pour une modification : éditer index.html ou styles.css dans GitHub, puis enregistrer. Vercel redéploie automatiquement après chaque mise à jour du dépôt connecté.
